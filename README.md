# Git-Based Collaborative Software Development Workflow
## Case Study
Open Source Technologies

## Objective
To demonstrate how Git supports version control,
collaboration, branching, merging, and conflict resolution.

## Tools
- Git
- Git Bash
- GitHub
- Visual Studio Code

## Workflow
1. Create a repository.
2. Create feature branches.
3. Commit code changes.
4. Merge feature branches.
5. Resolve merge conflicts.
6. Push changes to GitHub.
